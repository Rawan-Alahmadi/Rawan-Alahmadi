### <img src="https://cdn.simpleicons.org/github/8FA382" width="20" style="vertical-align:middle"/> California Housing — Price Prediction & Classification

A comparative machine learning study on the California Housing dataset, tackling the problem from two angles: classifying homes as "expensive" (Logistic Regression vs. Random Forest) and predicting exact median values (Linear vs. Polynomial Regression). Random Forest and Polynomial Regression both outperformed their baselines, with the Random Forest model reaching 89.7% accuracy and a 0.961 ROC-AUC.

`Python` `Scikit-learn` `Pandas` `Jupyter`

### <img src="https://cdn.simpleicons.org/github/D1A7AC" width="20" style="vertical-align:middle"/> Senad — Smart Municipal Service Prioritization

An intelligent decision-support system developed for the Holy Makkah Municipality (Amanah) to prioritize service requests across neighborhoods. Combines risk level, population, location scope, and report volume through ML models (Random Forest, XGBoost) to generate a ranked priority list — helping municipal teams allocate resources faster and more fairly.

`Machine Learning` `Random Forest` `XGBoost` `Streamlit` `Figma`
